Static HTML/CSS/JS Intellium Digital website with Maya Checkout serverless API for Vercel deployment.

Do not upload `.env` or secret keys.

Set these Vercel Environment Variables:
- `MAYA_CHECKOUT_PUBLIC_KEY`
- `MAYA_CHECKOUT_BASE_URL`
- `SITE_URL`

Production URLs:
- Webhook URL: `https://www.intelliumdigital.online/api/maya-webhook`
- Success URL: `https://www.intelliumdigital.online/success.html`
- Failure URL: `https://www.intelliumdigital.online/failed.html`
- Cancel URL: `https://www.intelliumdigital.online/failed.html`
